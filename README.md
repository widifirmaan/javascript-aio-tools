## Fitur

- **23 In-Browser Utilities**:
  - **File Encryptor (`tools/file-encryptor.html`)**: Client-side AES-GCM 256-bit encryption and decryption with PBKDF2 key derivation (100,000 iterations) using the native Web Crypto API.
  - **Steganography Studio (`tools/steganography.html`)**: Least Significant Bit (LSB) image steganography hiding text into RGB channels with optional AES-GCM password protection.
  - **Password Generator (`tools/password-generator.html`)**: Cryptographically secure random password generation (`crypto.getRandomValues`), Diceware passphrases, and Shannon entropy estimation.
  - **Photo Metadata Editor (`tools/photo-metadata.html`)**: Pure JavaScript binary EXIF parser displaying camera settings, shutter speed, and GPS coordinates with 1-click EXIF stripping for privacy.
  - **PDF Splitter (`tools/pdf-splitter.html`)**: Page range extraction and visual page thumbnail previews powered by PDF-Lib and Mozilla PDF.js.
  - **PDF Tools (`tools/pdf-tools.html`)**: Multi-document PDF merger and batch JPG/PNG/WebP images-to-PDF compiler.
  - **ASCII Art Generator (`tools/ascii-art.html`)**: Image-to-ASCII converter generating monochrome text, styled HTML, and 24-bit ANSI terminal color codes.
  - **Background Remover (`tools/remove-bg.html`)**: In-browser neural background removal powered by `@imgly/background-removal` WebAssembly runtime without uploading photos to external servers.
  - **Image Compressor (`tools/image-compressor.html`)**: Client-side Canvas image compressor with interactive quality slider and live file size preview.
  - **Image Converter (`tools/image-converter.html`)**: In-browser format conversion between JPG, PNG, and WebP using Canvas APIs.
  - **Color Palette Extractor (`tools/color-palette.html`)**: Dominant color extraction using Median-Cut color quantization with CSS variables, JSON, and PNG swatch card export.
  - **SVG Minifier (`tools/svg-minifier.html`)**: XML namespace cleaner, comment stripper, and coordinate precision optimizer with side-by-side vector preview.
  - **Audio Cutter (`tools/audio-cutter.html`)**: Interactive Web Audio waveform slicer with draggable handles, fade envelope curves, and PCM WAV export.
  - **Screen Recorder (`tools/screen-recorder.html`)**: Browser-native DisplayMedia and MediaRecorder screen video capture with microphone audio support and WebM download.
  - **Instrument Tuner (`tools/audio-tuner.html`)**: Real-time pitch detection via YIN autocorrelation algorithm with -50 to +50 cents deviation needle and live FFT spectrogram.
  - **Regex Visualizer (`tools/regex-visualizer.html`)**: Regular expression tester with dynamic SVG railroad track flow diagrams and capture group inspection.
  - **Text Diff (`tools/text-diff.html`)**: Longest Common Subsequence (LCS) text comparator with side-by-side split and unified diff modes.
  - **QR Code Studio (`tools/qr-code.html`)**: QR code generator for URLs, Wi-Fi, WhatsApp, and vCards, plus webcam and image QR scanner via Html5-QRCode.
  - **Developer Toolbox (`tools/dev-tools.html`)**: JSON Formatter & Validator, Base64/URL encoder-decoder, and client-side JWT token inspector.
  - **Text Editor (`tools/text-editor.html`)**: Clean distraction-free text editor with real-time character, word, and reading time counters.
  - **Barcode Studio (`tools/barcode-studio.html`)**: Pure JavaScript 1D vector barcode generator supporting Code 128, EAN-13, UPC-A, Code 39, and ITF-14.
  - **Scientific Calculator (`tools/calculator.html`)**: Client-side scientific calculator with trigonometric, logarithmic, and power functions.
  - **Tire Comparison (`tools/tire-comp.html`)**: Automotive tire specification comparator calculating sidewall height, rolling diameter, ground clearance delta, and speedometer error percentage.
- **100% Client-Side Privacy**: All file processing, cryptographic operations, image rendering, and document manipulation execute directly in browser memory—no files or metadata are uploaded to any server.
- **Zero Framework Runtime**: Built with Vanilla JavaScript (ES6+), HTML5, and CSS3 without external client-side framework overhead.

## Tech Stack

| Category | Technology | Description / Purpose |
| :--- | :--- | :--- |
| **Core Architecture** | Vanilla JavaScript (ES6+), HTML5, CSS3 | Framework-free client-side static web application |
| **Cryptography & Privacy** | Web Crypto API (`SubtleCrypto`), AES-GCM, PBKDF2 | Browser-native 256-bit file encryption and key derivation |
| **Document Processing** | Mozilla PDF.js `3.11`, PDF-Lib `1.17` | In-browser PDF parsing, previewing, splitting, and merging |
| **Audio & Media** | Web Audio API (YIN Autocorrelation), MediaRecorder | Waveform slicing, screen recording, and real-time audio pitch detection |
| **On-Device Machine Learning** | `@imgly/background-removal` (WebAssembly) | Neural network background removal running locally in the browser |
| **QR Code & Camera** | QRCode.js, Html5-QRCode `2.3` | Client-side QR generation and live webcam video stream decoding |
| **Barcode Generators** | Pure JS Barcode Encoders (128, EAN, UPC, 39, ITF) | Vector SVG barcode rendering based on binary pattern specifications |
| **UI & Styling** | Bootstrap `5.3`, Bootstrap Icons, AOS | Responsive modern dark interface with off-canvas mobile drawer |

## Tutorial Run Local & Setup

### 1. Prerequisites

- Any modern web browser (Google Chrome, Mozilla Firefox, Apple Safari, Microsoft Edge).
- Python 3 (`python3`) or Node.js (`npx serve`) to serve static HTML files locally.
- Database: **No database required** (100% static client-side application).

### 2. Environment Variables Setup

No environment variables are required.

### 3. Installation & Running the Local Server

```bash
# 1. Clone the repository
git clone https://github.com/widifirmaan/javascript-aio-tools.git
cd javascript-aio-tools

# 2. Run local static web server
# Option A: Using Python 3
python3 -m http.server 8000

# Option B: Using npx serve (if Node.js is installed)
npx serve .
```

Open [http://localhost:8000](http://localhost:8000) in your browser.
